# Portfolio

A responsive personal portfolio landing page built with semantic HTML, modern CSS, and a small amount of JavaScript for mobile navigation.

## Features

- Hero section with clear calls to action
- Project, skills, experience, and contact sections
- Responsive layout for desktop and mobile
- Accessible navigation and semantic content structure

## Run locally

Open `index.html` in a browser or serve the folder with a static server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
